## 4. 수업에 쓰는 도구 한 줄 설명

- **AWS Skill Builder**: AWS 공식 온라인 학습. 자격증(CLF·AIF) 과정은 여기 커리큘럼을 따른다.
- **AWS PartyRock**: 코드 없이 생성형 AI 앱을 만드는 Bedrock 놀이터. 리터러시 과정의 기본 실습.
- **CertiNavigator** (`certi.nxtcloud.kr`): 자사 자격증 학습 서비스. AIF 과정 수강생에게 안내한다.
- **Amazon Bedrock**: 파운데이션 모델 API. 교육에서는 LLM Gateway 가 발급한 키로 OpenAI 호환 방식으로 호출한다(`bedrock.nxtcloud.kr/v1`, 모델 별칭 `bedrock-haiku` 등).
- **Kiro**: AWS 의 AI 개발 도구. Steering·Spec 으로 요구사항을 코드로 잇는 흐름을 가르친다.
- **Strands Agents / Bedrock AgentCore**: 에이전트 프레임워크와 운영 환경. 중급심화 3일차.
- **Canva / Google AI Studio**: 리터러시 과정의 콘텐츠 제작·실험 도구. AI Makers 는 Canva 자료를 보며 수업을 진행하는 자사 도구다.

## 5. 신입이 체험할 순서 (교육 트랙 E8)

1. Skill Builder 의 AIF 과정에서 모듈 1~2 수강
2. PartyRock 으로 앱 1개 만들기 (수강생이 겪을 가입·한도 문제를 메모)
3. CertiNavigator 둘러보기
4. 중급심화 교안 M1·M2 슬라이드 훑기
5. "수강생이 할 법한 질문 3개" 를 과제로 제출
