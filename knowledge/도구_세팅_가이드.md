## 4. Google Drive

- 사업 폴더 규칙: `YYMM_기관명_과정명/` (YYMM = 교육 수행 연월). 하위에 `결과보고서/`, `사진/<n일차>/`, `출석부/`, `curriculum.md`.
- `0000_결과보고서_모음/` 은 과거 보고서 레퍼런스(양식·문체 참고용), `_보고서도구/` 는 hwpx·docx 편집 스크립트.
- Drive 데스크톱 앱을 설치하면 `~/Library/CloudStorage/GoogleDrive-<메일>/내 드라이브` 에 마운트된다. 로컬 파일처럼 읽고 쓸 수 있지만 **원본을 직접 편집하지 않는다**. 로컬 `…_수정본` 에서 고치고 `drive_sync.py` 로 반영한다.
- 마운트 캐시 때문에 다른 사람이 고친 파일은 `ls -lat` 를 두 번 실행해 크기·시각이 갱신되는지 확인한다.
- `.gdoc`·`.gform` 은 포인터 파일이라 로컬에서 내용을 읽을 수 없다. 내용이 필요하면 hwpx/docx 로 내려받는다.

## 6. 로컬 개발 도구

| 도구 | 쓰는 곳 | 비고 |
|---|---|---|
| Python 3.9 이상 | `_보고서도구/`(doctext·hwpx_edit·hwpx_table·drive_sync), 지식 수집 스크립트 | 표준 라이브러리만 사용 |
| Node.js 24 이상 | 자사 서비스(Next.js), AI Makers | |
| Docker | 로컬 Postgres, LLM Gateway PoC | |
| Terraform 1.13 이상 | 인프라 (LLM Gateway, 온보딩 플랫폼) | |
| AWS CLI | 프로필 기반. 자격증명은 `~/.aws/config` 에만 | 키를 리포·채팅·문서에 쓰지 않는다 |
| 한컴오피스 | **필요 없음.** hwpx 는 스크립트로 편집한다 | 구형 `.hwp` 만 한글에서 hwpx 로 저장 요청 |

## 7. 막혔을 때

- 계정·장비: `#help` 또는 운영 담당자
- AWS·프로필: 클라우드 담당자
- 이 문서에 없는 것: 온보딩 플랫폼 에이전트에게 묻는다. 문서에 없으면 담당자에게 전달해 준다.
