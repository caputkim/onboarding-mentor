# 자사 제품·서비스 안내

> 상태: 초안 (2026-10-29, 온보딩 플랫폼 MVP 용). LLM Gateway 와 AI Makers 는 리포 README 기준이고, CertiNavigator 와 AI Professor 의 세부 기능은 `[[확인 필요]]`.

## 1. CertiNavigator — `certi.nxtcloud.kr`

- AWS 자격증(AIF 등) 과정 수강생의 학습을 돕는 자사 서비스. 자격증 과정 교육에서 수강생에게 안내한다.
- 보고서 표기는 `CertiNavigator` (오타 주의: `CeritiNavigator` 아님).
- 세부 기능·운영 담당·수강생 가입 절차는 `[[확인 필요]]`.

## 2. LLM Gateway — `bedrock.nxtcloud.kr`

여러 AWS 계정(테넌트)의 Amazon Bedrock 을 **base URL 하나**로 서비스하는 LiteLLM 게이트웨이와 운영 콘솔. 넥스트클라우드 메인 계정에 허브 1대를 두고, 테넌트(대학·기관) 계정에는 IAM 역할 하나만 만든다. Bedrock 비용은 각 테넌트 계정에 청구된다.

| 역할 | 하는 일 | 보는 곳 |
|---|---|---|
| 수강생 | API 호출, 내 사용량 확인 | `bedrock.nxtcloud.kr/guide/` |
| 교육 운영자 | 교육 만들기, 키 발급·회수, 한도 조정, 사용량 확인 | 콘솔 `console.bedrock.nxtcloud.kr`, `포털 사용법` 문서 |
| 인프라 운영자 | 허브 배포, 테넌트 계정 추가, 장애 대응 | `운영 런북`, `테넌트 계정 추가` 문서 |

- 용어: **테넌트** = 비용을 내는 AWS 계정, **교육** = 학기 과목·해커톤 하나(총 누적 한도), **키** = 수강생 1명(1인 한도), **별칭** = 수강생이 쓰는 모델 이름(`bedrock-haiku` 등).
- 수강생 호출 예: OpenAI 호환 클라이언트에 `base_url="https://bedrock.nxtcloud.kr/v1"` 과 발급 키.
- 키 회수·한도 변경은 최대 60초 뒤 반영. 한도 초과(`422 budget_exceeded`)는 즉시.
- 리포에는 비밀이 없다. 마스터 키·DB 비밀번호·ExternalId 는 Secrets Manager·Terraform state·포털 DB 에만 있다.
- 교육 운영자는 브라우저만 있으면 된다. AWS 자격증명·CLI 는 필요 없다.

## 3. AI Makers — 수업 도우미

- 캔바 강의자료를 보면서 수업을 진행하고, 수강생의 작업물 URL 을 모으는 한국어 웹 서비스. 광주대 수업에 쓰였다.
- 흐름: 강사가 강의·과제 등록 → 수강생에게 8자리 참여 코드 전달 → 수강생이 이름과 URL 1~10개 제출(계정 없음) → 강사가 제출물 확인.
- Canva 의 **공유 → 더 보기 → 임베드** 주소를 강의 설정에 넣는다. 임베드가 공개된 자료여야 한다.
- 구조: React 정적 화면 + 서버리스 API(AWS). 디자인은 토스 스타일 가이드 기반.

## 4. AI Professor — 설계 중

- 강의자료를 올리면 수강생 질문에 답하는 AI 조교 서비스. 1단계 기능 정리·아키텍처·데이터 모델·강의자료 수집(ingestion)·Bedrock 프롬프트 설계 문서가 있다.
- 담당·일정·고객은 `[[확인 필요]]`.
