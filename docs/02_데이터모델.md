# 데이터 모델

> 작성 2026-10-29. Postgres + Prisma. 테넌트 축 없음 (사내 도구).
> 가시성 규칙은 `01_MVP_명세.md` §6 이 정본이며, 여기서는 그 규칙을 스키마가 어떻게 받치는지만 적는다.
> 2026-10-29 분리 후: 두 리포(`onboarding-newcomer` · `onboarding-mentor`)의 `web/prisma` 는 같은 스키마·마이그레이션의 사본이다. 스키마를 바꾸면 **양쪽을 같이** 고치고, 마이그레이션은 어느 쪽이 먼저 `migrate deploy` 해도 된다 (멱등). 새 마이그레이션(`npm run db:migrate`)은 mentor 에서 만들어 newcomer 로 복사한다.

## 1. 엔티티 개요

```
User ─┬─ Onboarding (newcomer) ─┬─ OnboardingTrack ── Track ── Phase ── TaskTemplate
      │                         ├─ TaskInstance ── Submission
      │                         ├─ AgentMemory (1:1)
      │                         ├─ WeeklySummary
      │                         └─ QueryLog ── Escalation ── DocDraft
      ├─ Onboarding (mentor)
      ├─ Conversation ── Message            ← 원문. 소유자(userId)만 읽음
      └─ Escalation (assignee)

Document ── DocSection                      ← 지식베이스
SyncRun, AuditLog                           ← 운영
```

| 엔티티 | 역할 | 비고 |
|---|---|---|
| `User` | 직원. 역할(신입·멘토·운영자)과 담당 영역 | 사람 디렉터리는 별도 테이블 없이 `User.responsibilities` 로 |
| `Track` / `Phase` / `TaskTemplate` | 플랜 템플릿. `plans/*.md` 가져오기의 결과 | 템플릿 수정은 이미 개설된 온보딩에 영향 없음 |
| `Onboarding` | 신입 1명의 온보딩 1건 | 트랙 여러 개 가능 (공통 + 교육) |
| `TaskInstance` | 템플릿을 시작일 기준 기한으로 펼친 것 | 상태 전이는 §3 |
| `Submission` | 제출물과 코치 피드백, 멘토 메모 | 재제출은 새 행 |
| `Conversation` / `Message` | 대화 원문 | API 에서 소유자 검사. 운영자 읽기 엔드포인트 없음 |
| `AgentMemory` | 신입별 맥락 요약 1건 | 원문 아님. 금지 목록 적용해 생성 |
| `QueryLog` | 질문 1건의 익명화 기록 | `normalizedQuestion` 은 에스컬레이션된 것만 노출 |
| `Escalation` / `DocDraft` | 담당자 전달과 답변, 문서 초안 | 초안 수락 시 `Document(MANUAL)` 생성 |
| `Document` / `DocSection` | 지식베이스 | 검색은 `pg_trgm`, 임베딩 컬럼은 2단계 |
| `WeeklySummary` | 멘토용 주간 요약 | 입력에 `Message` 없음 |
| `SyncRun` / `AuditLog` | 동기화 이력, 운영자 행위 기록 | |

## 2. Prisma 스키마 초안

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider   = "postgresql"
  url        = env("DATABASE_URL")
  extensions = [pg_trgm]
}

enum Role            { NEWCOMER MENTOR ADMIN }
enum OnboardingStatus{ PLANNED ACTIVE PAUSED COMPLETED }
enum TaskType        { READ SETUP QUIZ ASSIGNMENT MEETING SHADOWING }
enum TaskStatus      { TODO IN_PROGRESS SUBMITTED DONE BLOCKED SKIPPED }
enum Verdict         { PASS REVISE }
enum MessageRole     { USER ASSISTANT }
enum DocSource       { DRIVE GITHUB MANUAL }
enum DocVisibility   { ALL TRACK ADMIN }
enum EscalationStatus{ OPEN ANSWERED CLOSED }
enum DraftStatus     { PROPOSED ACCEPTED REJECTED }

model User {
  id               String   @id @default(cuid())
  email            String   @unique
  name             String
  role             Role     @default(NEWCOMER)
  title            String?                  // 직함
  responsibilities String[] @default([])    // 담당 영역 태그 — 사람 디렉터리
  active           Boolean  @default(true)
  createdAt        DateTime @default(now())

  onboardingsAsNewcomer Onboarding[]   @relation("Newcomer")
  onboardingsAsMentor   Onboarding[]   @relation("Mentor")
  conversations         Conversation[]
  escalationsAssigned   Escalation[]   @relation("Assignee")
  auditLogs             AuditLog[]
}

model Track {
  id          String  @id @default(cuid())
  slug        String  @unique            // common | education | msp | dev
  name        String
  description String?
  order       Int     @default(0)
  phases      Phase[]
  onboardings OnboardingTrack[]
}

model Phase {
  id              String @id @default(cuid())
  trackId         String
  track           Track  @relation(fields: [trackId], references: [id], onDelete: Cascade)
  name            String
  order           Int
  startOffsetDays Int    // 시작일 기준 D+n
  endOffsetDays   Int
  tasks           TaskTemplate[]
  @@unique([trackId, order])
}

model TaskTemplate {
  id            String   @id @default(cuid())
  phaseId       String
  phase         Phase    @relation(fields: [phaseId], references: [id], onDelete: Cascade)
  code          String                 // 플랜 md 의 ID (C1, E3 …). 가져오기 시 매칭 키
  title         String
  description   String                 // markdown
  type          TaskType
  dueOffsetDays Int
  evidence      String?                // 제출물 설명. null 이면 체크만으로 DONE 가능
  rubric        String?                // 코치 평가 기준 markdown
  docRefs       String[] @default([])  // Document.path 또는 외부 URL
  optional      Boolean  @default(false)
  order         Int
  instances     TaskInstance[]
  @@unique([phaseId, code])
}

model Onboarding {
  id         String           @id @default(cuid())
  newcomerId String
  newcomer   User             @relation("Newcomer", fields: [newcomerId], references: [id])
  mentorId   String?
  mentor     User?            @relation("Mentor", fields: [mentorId], references: [id])
  startDate  DateTime         @db.Date
  status     OnboardingStatus @default(PLANNED)
  createdAt  DateTime         @default(now())

  tracks     OnboardingTrack[]
  tasks      TaskInstance[]
  memory     AgentMemory?
  summaries  WeeklySummary[]
  queryLogs  QueryLog[]
  @@index([newcomerId])
  @@index([mentorId])
}

model OnboardingTrack {
  onboardingId String
  onboarding   Onboarding @relation(fields: [onboardingId], references: [id], onDelete: Cascade)
  trackId      String
  track        Track      @relation(fields: [trackId], references: [id])
  @@id([onboardingId, trackId])
}

model TaskInstance {
  id            String       @id @default(cuid())
  onboardingId  String
  onboarding    Onboarding   @relation(fields: [onboardingId], references: [id], onDelete: Cascade)
  templateId    String
  template      TaskTemplate @relation(fields: [templateId], references: [id])
  status        TaskStatus   @default(TODO)
  dueDate       DateTime     @db.Date
  completedAt   DateTime?
  blockedReason String?      // 신입이 적은 막힘 사유 — 주간 요약 입력에 포함
  submissions   Submission[]
  @@unique([onboardingId, templateId])
  @@index([onboardingId, status])
}

model Submission {
  id             String       @id @default(cuid())
  taskInstanceId String
  taskInstance   TaskInstance @relation(fields: [taskInstanceId], references: [id], onDelete: Cascade)
  content        String       // markdown 또는 링크
  verdict        Verdict?
  agentFeedback  Json?        // { findings: [{item, severity, quote?, suggestion}], summary }
  mentorNote     String?
  createdAt      DateTime     @default(now())
  @@index([taskInstanceId])
}

// ---------- 대화 원문: 소유자만 ----------
model Conversation {
  id           String    @id @default(cuid())
  userId       String
  user         User      @relation(fields: [userId], references: [id], onDelete: Cascade)
  onboardingId String?   // 온보딩 없는 직원의 지식 Q&A 는 null
  title        String?
  createdAt    DateTime  @default(now())
  updatedAt    DateTime  @updatedAt
  messages     Message[]
  @@index([userId, updatedAt])
}

model Message {
  id             String       @id @default(cuid())
  conversationId String
  conversation   Conversation @relation(fields: [conversationId], references: [id], onDelete: Cascade)
  role           MessageRole
  content        Json         // SDK 응답 content 블록 전체 (텍스트·tool_use·tool_result·thinking·compaction)
  createdAt      DateTime     @default(now())
  @@index([conversationId, createdAt])
}

model AgentMemory {
  id           String     @id @default(cuid())
  onboardingId String     @unique
  onboarding   Onboarding @relation(fields: [onboardingId], references: [id], onDelete: Cascade)
  summary      String     // 금지 목록 적용된 맥락 요약
  updatedAt    DateTime   @updatedAt
}

// ---------- 질문 로그 · 에스컬레이션 ----------
model QueryLog {
  id                 String      @id @default(cuid())
  onboardingId       String?
  onboarding         Onboarding? @relation(fields: [onboardingId], references: [id], onDelete: SetNull)
  askedById          String      // User.id — 집계 시 익명화. Message 와는 FK 없음 (원문 분리)
  normalizedQuestion String      // 이름·개인 맥락 제거한 일반형
  topic              String      // 자유 태그. 공백 리포트의 집계 키
  answered           Boolean
  citedDocIds        String[]    @default([])
  createdAt          DateTime    @default(now())
  escalation         Escalation?
  @@index([topic, answered])
  @@index([onboardingId, createdAt])
}

model Escalation {
  id          String           @id @default(cuid())
  queryLogId  String           @unique
  queryLog    QueryLog         @relation(fields: [queryLogId], references: [id], onDelete: Cascade)
  assigneeId  String?
  assignee    User?            @relation("Assignee", fields: [assigneeId], references: [id])
  question    String           // 신입이 확인한 전달 문구
  status      EscalationStatus @default(OPEN)
  answer      String?
  answeredAt  DateTime?
  createdAt   DateTime         @default(now())
  draft       DocDraft?
  @@index([assigneeId, status])
}

model DocDraft {
  id           String      @id @default(cuid())
  escalationId String      @unique
  escalation   Escalation  @relation(fields: [escalationId], references: [id], onDelete: Cascade)
  title        String
  content      String      // markdown
  status       DraftStatus @default(PROPOSED)
  documentId   String?     // 수락 시 생성된 Document
  createdAt    DateTime    @default(now())
}

// ---------- 지식베이스 ----------
model Document {
  id           String        @id @default(cuid())
  source       DocSource
  path         String        @unique   // drive:<폴더>/<파일> | github:<repo>/<path> | manual:<id>
  title        String
  summary      String                   // 한 줄 요약 — 카탈로그에 들어감
  tags         String[]      @default([])
  visibility   DocVisibility @default(ALL)
  trackSlug    String?                  // visibility=TRACK 일 때
  piiFlag      Boolean       @default(false)   // 개인정보 의심 — 운영자 확인 전 ADMIN
  contentHash  String
  sourceMeta   Json?                    // 원본 수정시각, 크기, 제외된 섹션 목록
  lastSyncedAt DateTime
  sections     DocSection[]
  @@index([source])
  @@index([visibility, trackSlug])
}

model DocSection {
  id         String   @id @default(cuid())
  documentId String
  document   Document @relation(fields: [documentId], references: [id], onDelete: Cascade)
  order      Int
  heading    String
  text       String
  tokenCount Int?
  // 2단계: embedding vector(1024)  ← Voyage AI
  @@unique([documentId, order])
}

// ---------- 운영 ----------
model WeeklySummary {
  id           String     @id @default(cuid())
  onboardingId String
  onboarding   Onboarding @relation(fields: [onboardingId], references: [id], onDelete: Cascade)
  weekStart    DateTime   @db.Date
  content      String     // markdown
  createdAt    DateTime   @default(now())
  @@unique([onboardingId, weekStart])
}

model SyncRun {
  id         String    @id @default(cuid())
  source     DocSource
  startedAt  DateTime  @default(now())
  finishedAt DateTime?
  added      Int       @default(0)
  updated    Int       @default(0)
  skipped    Int       @default(0)
  excluded   Json?     // 필터에 걸린 파일·섹션 목록
  log        String?
}

model AuditLog {
  id        String   @id @default(cuid())
  actorId   String
  actor     User     @relation(fields: [actorId], references: [id])
  action    String   // onboarding.create | document.visibility | draft.accept | …
  target    String   // 엔티티 id
  detail    Json?
  createdAt DateTime @default(now())
  @@index([actorId, createdAt])
}
```

### 스키마 밖에서 해야 하는 것 (마이그레이션 SQL)
- `CREATE EXTENSION IF NOT EXISTS pg_trgm;`
- `Document(title, summary, tags)` 와 `DocSection(heading)` 에 GIN trigram 인덱스.
  한국어는 형태소 분석 없이 trigram 이 가장 무난하다. 정확도는 카탈로그 선택(에이전트)이 보완한다.
- 2단계 임베딩 추가 시 `CREATE EXTENSION vector` 와 `DocSection.embedding vector(1024)`.

## 3. 상태 전이

### TaskInstance
```
TODO ──▶ IN_PROGRESS ──▶ SUBMITTED ──(PASS)──▶ DONE
  │           │              └──(REVISE)──▶ IN_PROGRESS
  │           └──▶ BLOCKED ──▶ IN_PROGRESS
  └──▶ SKIPPED   (optional=true 인 과제만. 운영자·멘토가 처리)
```
- `evidence` 가 있는 과제는 `SUBMITTED` 를 거치지 않고 `DONE` 이 될 수 없다 (`update_task_status` 가 거부).
- `BLOCKED` 는 `blockedReason` 필수. 주간 요약과 멘토 화면에 바로 뜬다.

### Escalation
`OPEN` → `ANSWERED` (담당자 답변, `DocDraft` 자동 생성) → `CLOSED` (신입이 확인 또는 7일 경과).

### DocDraft
`PROPOSED` → `ACCEPTED` (운영자. `Document(MANUAL)` 생성, `documentId` 기록) / `REJECTED`.

## 4. 접근 제어를 스키마가 받치는 방식
- `Message` 는 `Conversation.userId` 를 거쳐서만 조회한다. 서비스 계층에 `getMessages(conversationId, requesterId)` 하나만 두고 `requesterId !== conversation.userId` 면 404.
- 운영자용 메시지 조회 엔드포인트를 만들지 않는다. 운영 목적의 디버깅은 DB 직접 접근(감사 대상)으로만.
- `QueryLog` 는 `Message` 와 FK 가 없다. 로그에서 원문으로 되돌아갈 경로를 두지 않는다.
- `QueryLog.askedById` 는 보존 기간 뒤 null 처리해 집계만 남긴다.

## 5. 플랜 md → 템플릿 가져오기 규칙
`plans/*.md` 의 형식(`## Phase:` 제목 + 표)을 파싱한다. 표 열은 다음 순서로 고정한다.

| 열 | 매핑 |
|---|---|
| ID | `TaskTemplate.code` |
| 제목 | `title` |
| 유형 | `type` (READ·SETUP·QUIZ·ASSIGNMENT·MEETING·SHADOWING) |
| 기한 | `dueOffsetDays` (D+n 의 n) |
| 설명 | `description` |
| 제출물 | `evidence` (비어 있으면 null) |
| 평가 기준 | `rubric` |
| 참고 문서 | `docRefs` (쉼표 구분) |
| 선택 | `optional` (`선택` 이면 true) |

- 같은 `code` 가 있으면 갱신, 없으면 추가, md 에서 사라진 항목은 **삭제하지 않고** 운영자에게 표시한다.
- 가져오기 전 diff 를 콘솔에 보여주고 확인 후 반영한다.
